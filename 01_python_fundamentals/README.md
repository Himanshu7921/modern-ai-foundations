# Python Programming Fundamentals

Welcome to the **Python Programming Fundamentals** module. This folder contains all the core resources, interactive notebooks, and assessment files required to build a rock-solid foundation in Python before diving into Machine Learning and Deep Learning architectures.

## Learning Assets

### 1. Interactive Lecture Notes (`notebooks/`)

The `notebooks/` directory includes comprehensive `.ipynb` files covering your day-to-day lectures:

* Complete code syntaxes with minimal, readable comments.
* Structural comparisons highlighting execution differences between Python and statically typed languages like Java.
* Real-world edge cases evaluating Mutability vs. Immutability across Data Collections.
* Deep dives into structural Object-Oriented Programming (OOP) paradigms.

### 2. Practical Assessments (`assignments/`)

The `assignments/` folder holds a total of **7 structured coding assignments** engineered to transition you from code syntax memorization to programmatic logic implementation. Tasks include:

* Built-in Collections configurations, Loops, and Context Filters.
* Advanced Multi-dimensional array handling and NLP String Tokenization.
* Developing production-ready, abstract, and tightly encapsulated system models (e.g., Banking Architecture and ML Layer Pipelines).
