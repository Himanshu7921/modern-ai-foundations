## Detailed Course Curriculum

### Module 1: Python Programming Fundamentals

* **Core Topics:** Variables, Data Types, Conditional Statements, Control Flow Loops, and Functions.
* **Object-Oriented Programming (OOP):** Classes, Objects, Inheritance, Encapsulation, and Polymorphism.
* **Learning Outcome:** Synthesize structured, production-ready Python applications utilizing robust object-oriented design patterns.

### Module 2: Numerical Computing with NumPy

* **Core Topics:** Multi-dimensional Array Initialization, Array Operations, Element-wise Broadcasting, and Vectorization.
* **Linear Algebra Operations:** Dot Products, Cross Products, and Matrix Multiplication.
* **Learning Outcome:** Understand the algorithmic representations and vectorized processing models used to manipulate tensor data within machine learning workflows.

### Module 3: Data Analysis with Pandas

* **Core Topics:** Series and DataFrames, File I/O (CSV parsing), Exploratory Data Analysis (EDA), and Missing Value Imputation.
* **Data Manipulation:** Filtering, Sorting, GroupBy Aggregations, and Advanced Data Cleaning Techniques.
* **Learning Outcome:** Ingest, clean, transform, and prepare highly unstructured real-world datasets for downstream predictive modeling.

### Module 4: Data Visualization with Matplotlib

* **Core Topics:** Line Plots, Scatter Plots, Histograms, Bar Charts, and Multi-figure Layout Customization.
* **Analytical Visualization:** Statistical Dataset Exploration and Visual Pattern Recognition.
* **Learning Outcome:** Implement advanced data visualization strategies to extract actionable insights and identify distributions prior to model deployment.

### Module 5: Mathematics for Neural Networks

* **Linear Algebra:** Scalars, Vectors, Matrices, and Linear Transformations.
* **Multivariate Calculus:** Derivatives, Partial Derivatives, Gradients, and the Chain Rule.
* **Probability & Statistics:** Mean, Variance, Standard Deviation, and Fundamental Data Distributions.
* **Optimization:** Mathematical Intuition of Loss Functions, Cost Functions, and Optimization Profiles.
* **Learning Outcome:** Establish the complete mathematical foundation necessary to dissect how deep learning architectures optimize and converge.

### Module 6: Neural Networks from Scratch

* **Core Topics:** Biological Inspiration, Perceptrons, Artificial Neurons, and Forward Propagation.
* **Optimization & Training:** Activation Functions (Sigmoid, Tanh, ReLU, Softmax), Gradient Descent, and Backpropagation.
* **Classification Frameworks:** Binary and Multi-Class Task Architecture, Regularization, Overfitting, and Underfitting.
* **Learning Outcome:** Construct and debug an operational multi-class neural network classifier using mathematical first principles without external framework abstractions.
* **Module Project:** Dog vs Cat Image Classifier built completely from scratch using raw Python.

### Module 7: Deep Learning with PyTorch

* **Core Topics:** PyTorch Tensors, Automated Differentiation Engine (Autograd), Datasets, and DataLoaders.
* **Model Development:** Custom Layer Architecture, Training and Validation Loops, and Evaluation Metrics.
* **Computer Vision Workflows:** Convolutional Neural Network (CNN) Fundamentals, Transfer Learning, and Production Workflows.
* **Learning Outcome:** Design, train, evaluate, and serialize deep learning architectures utilizing industry-standard framework pipelines.
* **Module Project:** Convolutional Neural Network (CNN) for Production-Grade Image Classification.

### Module 8: Introduction to Generative AI

* **Core Topics:** High-Level Generative AI Architecture, Transformer Mechanics (ChatGPT), Tokenization, and Dense Embeddings.
* **Vector Architectures:** Vector Databases, Similarity Search Algorithms, Prompt Engineering, and Context Window Dynamics.
* **Systems Design:** Mitigation of LLM Hallucinations and Foundations of Retrieval-Augmented Generation (RAG).
* **Learning Outcome:** Master the architectural building blocks underlying enterprise LLM systems such as ChatGPT, Claude, and Gemini.
* **Module Project:** Document-Based Question-Answering (Q&A) System using RAG Architecture.
